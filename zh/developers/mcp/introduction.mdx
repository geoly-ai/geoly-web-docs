在 AI 助手里直接问品牌在 AI 搜索中的表现，答案来自你真实的 GEOly 数据。支持 Claude、Cursor、Codex、VS Code、Windsurf，以及其他支持远程 MCP 的客户端。

## 能做什么

- **查品牌可见度**：ChatGPT、Gemini、Google AI Mode、Google AI Overview 上的可见度、提及率、提及份额、引用率，以及表现最好和最差的平台。
- **看趋势**：按天、按平台或按 topic 的走势，并和上一周期对比。
- **和你跟踪的竞品比**：品牌排行榜、品牌 × 平台矩阵，以及 AI 常把哪些品牌和你一起提到。
- **读 AI 的原始回答**：每条提示词在每个平台上的回答、回答里提到的品牌和引用的来源。
- **分析引用**：AI 为你的提示词引用了哪些域名和 URL、其中有没有你自己的网站，以及 AI 直接写进回答里的链接。
- **找盲区**：AI 从来不提你的提示词，以及你在某个平台上偏弱的 topic。
- **看 AI 怎么评价你**：情感倾向、AI 夸你或批评你的属性，以及原话。
- **跟踪 AI 购物**：你的商品在 ChatGPT 和 Google AI Mode 购物卡片里的出现情况，以及你缺席时货架被谁占了。
- **检查你的网站**：GEO 诊断结果、Agent 就绪度扫描，以及来自 GA4 或 Cloudflare 的 AI 引荐流量。
- **研究市场**：用公开行业数据看品类领先者、品牌势头、空白机会、AI 搜索需求和 AI 购物榜。
- **一键出报告**：7 个内置[斜杠命令](/zh/developers/mcp/prompts)，比如周报、竞品雷达、活动追踪。
- **管理监控配置**：新建品牌、topic、提示词和竞品，给提示词改标签或换 topic、归档提示词，或立即跑一次监控。每次改动前客户端都会先请你确认。

## 怎么用

**1. 连接**

把服务器地址加到你的 AI 工具里。各客户端的具体步骤见[接入指南](/zh/developers/mcp/setup)。

**2. 登录授权**

客户端会在浏览器里打开 GEOly。选择组织，以及允许客户端读取或修改哪些内容，然后确认。每个客户端只需要授权一次。

**3. 提问或运行斜杠命令**

直接用日常语言问：

- *「最近 30 天我们在 ChatGPT 上的可见度变化如何？」*
- *「这周哪个竞品涨得最多？在哪个平台上？」*
- *「哪些提示词从来没有提到我们？」*

也可以从斜杠菜单里选一个内置[命令](/zh/developers/mcp/prompts)，直接拿到成型报告。

## 连接参数

客户端可能会要求填写下面这些信息：

| 项目 | 值 |
| - | - |
| **服务器地址** | `https://app.geoly.ai/api/mcp/v1` |
| **传输方式** | Streamable HTTP |
| **认证方式** | OAuth 2.1（在浏览器里登录授权） |

不带 `/v1` 的 `https://app.geoly.ai/api/mcp` 指向同一个服务器。也可以在 GEOly 的 **设置 → 开发者 → MCP 接入** 里复制地址。

## 认证

客户端会在浏览器里打开 GEOly 的授权页。登录后选择：

- **组织范围**：选一个组织，就能读取并修改它；选「全部组织」可以跨组织读取，但这次连接会关闭所有写入工具，避免改动落到错的组织。
- **按资源分开的读写权限**：品牌、topic、提示词、竞品、引用、情感、平台、分析、诊断、信源、公开数据、监控运行各有独立的读、写开关。只给客户端确实要改的资源开写入。

连接以你的身份访问数据：只能访问你所属的组织，以及你的角色在后台本来就能看到的数据。

<Note>
已有的只读 `geom_` 令牌仍然可用。新连接请使用 OAuth。
</Note>

## 读写权限

大部分工具只读取数据。会改动配置的有 8 个：`create_brand`、`create_topic`、`create_prompt`、`update_prompt_tags`、`move_prompts_to_topic`、`archive_prompt`、`create_competitor` 和 `trigger_prompt`。

所有写入工具都标记了 `readOnlyHint: false`，会替换已有数据的两个（`update_prompt_tags`、`move_prompts_to_topic`）还标记了 `destructiveHint: true`，客户端会在执行前请你确认。`trigger_prompt` 会真的发起一次监控。

全部工具见[工具参考](/zh/developers/mcp/tools)。

## 套餐与 MCP 额度

读取你自己的数据和公开行业数据会消耗 **MCP 额度**（MCP Credits），这是整个组织共用的月度额度。导航、发现、网站诊断、网站流量、所有写入工具，以及三个公开信源工具都免费。

| 套餐 | 每月 MCP 额度 |
| - | - |
| Basic | 3,000 |
| Grow | 25,000 |
| Advanced | 75,000 |
| Plus | 200,000 |
| Enterprise | 不限，或按合同约定 |

- **每个工具单独定价**：工具说明的最后一行写着它的价格：免费、按次固定价格（1、3 或 10 额度），或按返回行数计价。全部价格见[工具参考](/zh/developers/mcp/tools)。
- **公开行业情报**需要 Grow 及以上套餐，并授予公开数据的读取权限。
- **失败不扣费**：报错和超时都不扣额度。单次调用最多扣 2,500 额度。
- **查余额**用 `get_quota`（免费）。每次计费调用也会返回 `_quota` 回执，含本次费用和剩余额度。余额显示 `-1` 表示不限额。
- **额度用完后**，免费工具照常可用；计费工具会返回额度不足的提示，直到订阅日额度重置。

MCP 额度和 AI 额度（AI Credits）是两套独立的额度，后者用于 GEOly 后台里的 AI 功能。

## Agent Skill

MCP 连接决定 AI 助手能访问什么，GEOly Agent Skill 则教它怎么用好：先确认组织和品牌、选对工具、按后台的口径解释每个指标。技能不会增加权限或额度。建议和 MCP 一起[安装技能](https://www.geoly.ai/zh/open/skill)。

## 支持的客户端

支持 Streamable HTTP 远程 MCP 的客户端都可以使用。有分步说明的客户端：

- Claude Code
- Claude Desktop 和 claude.ai
- Codex（GEOly 官方插件）
- Cursor
- VS Code（GitHub Copilot）
- Windsurf

详见[接入指南](/zh/developers/mcp/setup)。

## 前提条件

- 一个 GEOly 账号，所在组织至少有一个品牌
- 带 MCP 额度的付费套餐（公开行业情报需要 Grow 及以上）
- 支持远程 MCP 的客户端
