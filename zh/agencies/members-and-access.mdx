---
title: "成员与客户访问"
description: "代理商团队里谁能做什么、项目角色怎么用，以及怎么让客户只能看到他自己的项目。"
---

GEOly 所有套餐的席位都不限，整个团队和客户都可以拉进来，不用多付钱。每个人能看什么、能做什么，取决于他的组织角色；如果是组织成员，还取决于他被加进了哪些项目。

<Note>
正文先写英文界面上的名称，括号里是中文界面的对应名称。
</Note>

## 组织角色

| 角色 | 能做什么 |
| --- | --- |
| **Owner**（所有者） | 完整权限：账单、成员、API 密钥和全部项目。 |
| **Admin**（管理员） | 可以邀请和移除成员、管理全部项目，但不能调整组织角色。 |
| **Member**（成员） | 只能看到被加进去的项目，身份是 **Project admin**（项目管理员）或 **Viewer**（只读成员）。 |

在代理商套餐里，下面这些只有所有者和管理员能做：

- 购买、升级、取消套餐（账单页也只对他们显示）；
- 给项目设最多提示词和平台；
- 新建试跑项目、把试跑项目转正；
- 暂停、恢复、设到期时间、删除项目。

所有者把所有权转给别人后，原所有者变成管理员。

## 项目角色

所有者和管理员能看全部项目。其他人只能看到被加进去的项目，并且是下面两种角色之一：

| 项目角色 | 在这个项目里能做什么 |
| --- | --- |
| **Project admin**（项目管理员） | 修改这个项目的数据、设置和集成，并管理项目成员。 |
| **Viewer**（只读成员） | 查看这个项目的数据、和 Agent 对话，但不能做任何修改。 |

## 外部协作者

外部协作者（Outside collaborator）不是组织成员：

- 只能打开被加进去的项目；
- 看不到组织成员名单和组织设置；
- 不计入组织成员人数；
- 收不到共享给整个组织的技能，Agent 也不带公司上下文；
- 被移出最后一个项目时，同时离开组织。

在 **Settings → Organization → Members**（设置 → 组织 → 成员）里，可以用 **Convert to outside collaborator**（转为外部协作者）把成员改成外部协作者，也可以用 **Convert to organization member**（转为组织成员）反过来。转换前后，他所在的项目和项目角色都不变。

## 让客户访问自己的项目

把客户以外部协作者的身份加进他自己的项目，角色设为 **Viewer**（只读成员）。这样他只能看到自己的项目，看不到你组织里的其他东西。如果要让客户也能改项目，就改用 **Project admin**（项目管理员）。

**从客户的项目里加：**

1. 切换到客户的项目，打开 **Settings → Project → Members**（设置 → 项目 → 成员）；
2. 点 **Add people**（添加成员），填入客户的邮箱。组织外的人接受邀请后以外部协作者身份加入，只能访问这个项目；
3. 角色选 **Viewer**（只读成员），发出邀请。

**从组织成员页加：**

1. 打开 **Settings → Organization → Members**（设置 → 组织 → 成员），点 **Invite**（邀请）；
2. 填入客户的邮箱；
3. 在 **Access**（访问范围）里选客户的项目，角色选 **Viewer**（只读成员），不要选 **Organization admin (all projects)**（组织管理员（全部项目））；
4. 关掉 **Organization member**（组织成员）开关。关着时，对方只以外部协作者身份加入这个项目；
5. 点 **Send Invitation**（发送邀请）。

客户会收到邀请邮件，接受后加入。他需要有 GEOly 账号才能登录。

<Tip>
自己团队的人以组织成员身份加入。只负责部分客户的客户经理，可以设成成员，在这些项目里担任 **Project admin**（项目管理员）。组织管理员只给管账单、额度和项目的人。
</Tip>
